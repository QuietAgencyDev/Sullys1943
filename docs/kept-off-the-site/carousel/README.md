# Homepage atmosphere carousel

Drop JPG/PNG/WebP files in this folder, then add them to:

`apps/web/src/lib/home-carousel.ts`

Example:

```ts
{
  src: "/carousel/kids-03.jpg",
  alt: "Youth sparring at Sully's Boxing Gym",
},
```

**Tips**
- Landscape ~16:10 works best
- ~1600px wide is plenty
- Keep files under ~500KB when possible

Current starter shots: `kids-01.jpg`, `kids-02.jpg` (plus existing `/gym/*` photos in the list).
