# Kids / Youth Program

## Purpose

Deliver an **incredible youth system** that parents trust and kids love — safety, clarity, skill progression, and communication — without exposing minors to adult social risks.

---

## Parent Capabilities

| Capability | Notes |
|------------|-------|
| Class bookings | Age-eligible sessions on parent + child calendar |
| View attendance | Same-day + history |
| Coach feedback | Notes / stamps surfaced in parent hub |
| Skill progression | Trees + stamps; boxing-appropriate |
| Pay fees | Family invoicing |
| Sign waivers | Minor + medical + photo; **waiver status** always visible |
| Announcements | Program-scoped |
| Achievements | Badges/skills |
| Nutrition lessons | Age-appropriate modules |
| Camp registrations | Camps + parties as products |
| Report cards | Periodic coach summaries |
| Coach messaging | Audited threads |
| Upcoming events | Kids camp, fight night (age-appropriate), closures |

**Parent hub rule:** One screen should answer — *Is my kid booked, safe (waiver), progressing, and what happens next?*

---

## Child vs Teen

| | Child (~≤12) | Teen (13–17) |
|--|--------------|--------------|
| Login | Optional / parent-mediated | Own login |
| Check-in | Proxy OK | Self QR |
| Booking | Parent | Self or approve |
| Community | View announcements only | Limited, moderated |
| Messaging | Via parent | Via parent CC optional |
| Purchases | Parent | Threshold approval |

Exact ages configurable per location.

---

## Skill Progression

- Skill trees per program (e.g., stance, jab, defense, respect/values)
- Coach stamps proficiency: `introduced | practicing | consistent | leadership`
- Visual progress for kids; detailed for parents
- Feeds report cards

---

## Report Cards

- Cadence: monthly / end of camp
- Sections: attendance, skills, coach comments, goals next period, values
- PDF + in-app
- Parent acknowledgement optional

---

## Safety & Compliance

- Guardianship verification (attestation + staff spot-check)
- Photo consent gates media in community/events
- No public discovery of child profiles
- Data minimization in notifications
- Pickup authorization list (Should): who may collect child
- Incident report workflow → notify parents + owner

---

## Camps & Parties

- Package products with roster
- Schedule blocks
- Waivers bundle
- Add-ons (cake, pizza via Kitchen — careful allergens)

---

## Coach UX

- Kid-friendly roster with medical **alert icons** (not full narrative by default)
- Quick stamp UI during class
- Batch parent message ("Great energy today!")

---

## Success Metrics

- Parent NPS
- Youth attendance consistency
- Report card open rate
- Youth → teen retention
- Message response time
