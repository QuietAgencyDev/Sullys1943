# Events

## Purpose

Operate and monetize Fight Nights, seminars, workshops, camps, fundraisers, BBQs, competitions, birthday parties — with tickets, waivers, and check-in.

---

## Event Types (Configurable)

- Fight Nights
- Seminars
- Nutrition Classes / Cooking Workshops
- Kids Camps
- Fundraisers / Community BBQ
- Competitions
- Birthday Parties
- Corporate buyouts

Overlap with Class Management: **recurring training = Classes**; **ticketed/special = Events**. Camps may use either; pick one model per product to avoid dual systems — recommendation: camps as `session_series` in Classes with Events used when public ticketing/marketing needed.

---

## Lifecycle

```
draft → published → sales_open → sold_out → in_progress → completed → archived
cancelled
```

---

## Ticketing

- Ticket types (VIP, general, competitor, child)
- Capacity per type
- Stripe payment
- Promo codes
- Guest checkout optional for public fight nights (still create account)
- Refund policies

---

## Compliance

- Event-specific waivers (competition, spectator, photo)
- Age gates
- Athlete bout registration (competition extension)

---

## On-Site

- Ticket QR check-in
- Door list mode
- Upsell merch/kitchen

## Marketing

- Public event page
- Share links
- Reminder sequences
- Post-event gallery (consent)

## Owner Metrics
