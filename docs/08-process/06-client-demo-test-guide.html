3. Prep (2 minutes)

  1. Open Floor TV: https://www.sullys1943.com/tv/floor
  2. Hard refresh (Ctrl+Shift+R).
  3. Tap Tap for sound / Test sound once (required for browser audio).
  4. Optional: press F for fullscreen.
  5. Keep speakers unmuted / volume up.

4. Full demo script

A. Public website (brand + photos)

  1. Open https://www.sullys1943.com
  2. Confirm homepage photo carousel auto-scrolls (youth + Rival + gym shots).
  3. Open /coaches — real trainer roster (initials until headshots land).

B. Member journey

  1. Open Member login
  2. Tap Fill member demo (or member@sullys.local / password123).
  3. Sign in → Member home (Gavin).
  4. Walk: Book a class, Digital card, Passport / XP.
  5. Sign out from Profile before switching to coach.

C. Coach Live + Boxing Timer (main demo)

Option 1 — Phone coach

  1. Login → Fill coach demo
  2. Open /app/coach
  3. Tap Demo Live Class → Open Live Mode

Option 2 — Staff console

  1. Staff console
  2. Sign in: coach@sullys.local / password123
  3. Coach → today’s class → Live

Timer test

  1. Tap Demo · 45 / 15 / 3
  2. Optional: Enable sound on coach device
  3. START — Floor TV countdown follows
  4. At 0:10 — wooden double clap on TV
  5. At 0:00 — end bell
  6. Test PAUSE, START (resume), RESET, STOP, then FINISH once at end

TV celebrations

  1. Show achievement / XP bonus / Class complete
  2. Confirm Floor TV flips modes
  3. Return to TIMER
