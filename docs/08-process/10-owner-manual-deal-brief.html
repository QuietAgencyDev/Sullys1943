3. Owner feature manual (client-side)

A. Owner desk Live

Staff → sign in as owner → Owner desk.

  • Money to Sully’s — today & month totals, split by tender (cash / card / mock)
  • Memberships — kids/youth vs adult counts + product breakdown
  • Waivers — signed today vs still unsigned
  • Walk-ins — sales count, check-ins, dollar amount
  • Demographics — under-18 vs 18+ when DOB is on file
  • Group message — blast youth, adult, monthly, trial, drop-in, or unsigned-waiver members
  • Floor pulse — check-ins, classes, kitchen open tickets, staff overrides
  • QuickBooks — status panel (planned; see QB PDF)

B. Front desk Live

  • USB / wedge scanner check-in with today’s class attached
  • Staff override with reason when waiver/membership blocks (audited)
  • Member search → check-in
  • Sell drop-in — CASH or CARD buttons ($25 same-day) → hits owner revenue
  • Link child to parent (guardianship + youth waiver packet)
  • Kiosk + dry-run paths available from staff hub

C. Coach Live + Floor TV Live

  • Phone coach (/app/coach) or Staff Live Mode
  • Demo preset 45s / 15s / 3 rounds for fast client demos
  • START / PAUSE / RESET / STOP / FINISH
  • TV: wooden double-clap ≤10s, bell at 0, celebration modes (XP / achievement / complete)
  • Tap “Test sound” once on the TV browser so audio unlocks

D. Member experience Live

  • Join / login, book classes, digital membership card
  • QR / token check-in path
  • Passport / XP progression (beyond “just booked a class”)
  • Digital waivers (self + guardian for youth)
  • Billing history (mock until Helcim cutover)

E. Public brand site Live

  • Homepage atmosphere + youth/Rival photo carousel
  • Official coaches roster page
  • Programs / join / contact entry points
  • Same org data as the gym OS — not a disconnected brochure site

F. Kitchen KDS Live · paid checkout Next

  • Staff kitchen tickets / allergen-aware board already on the OS
  • Card pay for kitchen attaches after Helcim payment abstraction

G. Admin Live

  • Invite / role-change / disable staff accounts (owner or admin)
