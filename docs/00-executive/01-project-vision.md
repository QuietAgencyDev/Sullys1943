# Project Vision

## Vision Statement

**Sully's Digital Performance Platform** is the operating system for Canada's oldest boxing gym — and eventually every Sully's location. It unifies a world-class public website, member portal, and in-gym operating system so the brand feels like a **professional sports organization**, not a neighborhood flyer taped to generic gym software.

We are not building “a website plus an app.”  
We are building **one connected ecosystem**: website → member portal → gym OS (desk, coaches, kitchen, kids, parents, waivers, POS, community, signage, TVs, analytics, Sully AI).

---

## The Irreplaceable Asset

Sully's owns what most gyms cannot buy: **80+ years of legacy (EST 1943)** — Canada's oldest boxing gym — associated with legends such as **Muhammad Ali, Lennox Lewis, George Chuvalo, Clyde Gray, Fern Bull, and Razor Ruddock**, while developing thousands of young athletes.

Digital must **sell memberships** and **tell that story** (Legacy Wall, Trophy Room, Boxing Passport) while running the modern facility.

---

## North Star

> Every member who walks through Sully's doors should feel as guided, tracked, and celebrated digitally as they do on the floor — and every owner should see the business as clearly as a fighter sees an opponent.

**North Star Metric (NSM):** Weekly Active Training Members (WATM) — members with ≥1 class check-in or logged workout in the last 7 days, per location.

**Supporting metrics:** Membership retention (90-day), class utilization, kitchen attach rate, parent engagement rate (youth), NPS, website → join conversion, digital check-in rate.

## Strategic Bets

1. **Check-in is the heartbeat** — powers XP, TVs, Command Center, passport.  
2. **Calendar is the hub** — training, nutrition, challenges, events — not a class grid only.  
3. **Legacy is a product** — Wall, Trophy Room, Passport — not an About blurb.  
4. **Website and OS share one database** — live spots, join funnel, no dual systems.  
5. **Youth = lifetime LTV.**  
6. **Kitchen + nutrition on calendar** = daily habit loop.  
7. **Every screen connected** — app, desk, KDS, TV1–5, owner.  
8. **Franchise architecture early, franchise UI later.**  

---

## Non-Goals (Explicit)

- Generic multi-sport club software first  
- Replacing clinical EHR  
- Public social network (community is private / gym-scoped)  
- Custom payment processor  
- Shipping Sully AI before clean operational data  
- Treating the website as a disconnected WordPress brochure forever

## Vision Guardrails

1. Does this increase WATM, retention, join conversion, or location revenue?  
2. Does it honor **EST 1943** legacy without legal/rights risk?  
3. Does it work for minors/parents?  
4. Is it location-aware and franchise-safe?  
5. Does every new screen use the **same live data plane**?  
6. Does the UX feel like **Sully's**, not generic SaaS?
