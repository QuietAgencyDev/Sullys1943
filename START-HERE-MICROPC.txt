Sully's on the MicroPC — no internet
======================================

Double-click this file on the USB:

    Start Sullys.bat

That is the whole install. Node.js 24 LTS is already on the stick.
If you already installed Node.js 24 on the mini PC, this still works.
The typefaces are on the stick. The app does not download fonts.
The local database is already built. The browser opens only after the site is listening.
If the page says localhost refused to connect, look at the window titled Sully's Website.
The first double-click opens:

    Floor TV     http://localhost:3000/tv/floor
    Public site  http://localhost:3000/
    Staff        http://localhost:3001/

Leave the three black windows open while you use the app.
If Windows asks, allow Node on private networks.
If a window says SmartScreen, choose More info, then Run anyway.

Do not run npm install. The libraries are already in node_modules.

To keep Sully's after you unplug the USB, double-click:

    Install to this PC.bat

That copies everything to C:\Sullys and puts Start Sullys on the desktop.
Then you can unplug the stick and run it from this PC.
