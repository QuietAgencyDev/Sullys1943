Sully's — run this copy on the MicroPC
======================================

This stick has the app source (no node_modules). On the MicroPC:

1. Install Node.js 20 LTS from https://nodejs.org
2. Open a terminal in this folder (E:\SULLYS or wherever you copied it)
3. npm install
4. npm run db:sqlite
5. In three terminals (or one after another in background):
     npm run dev:api
     npm run dev:web
     npm run dev:staff

Then open:
  Floor TV (Coach):  http://localhost:3000/tv/floor
  Public site:       http://localhost:3000/
  Staff:             http://localhost:3001/

.env files were not copied. Use .env.example if you need local secrets.
